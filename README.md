# Golden Bowl 🍜

A modern, responsive restaurant website built with React, Vite, and Tailwind CSS.

**Live Site:** [gbres.netlify.app](https://gbres.netlify.app)

## Overview

Golden Bowl is a sleek and user-friendly restaurant website showcasing dining experiences. The site is built with modern web technologies and features a responsive design that works seamlessly across all devices.

## Tech Stack

- **Frontend Framework:** [React](https://react.dev/) - A JavaScript library for building user interfaces
- **Build Tool:** [Vite](https://vitejs.dev/) - Next generation frontend tooling for fast development
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) - A utility-first CSS framework
- **Routing:** [React Router](https://reactrouter.com/) - Client-side routing for navigation
- **Icons:** [Font Awesome](https://fontawesome.com/) - Beautiful, professional icons

### Development Stack

- **Linting:** ESLint with React plugin for code quality
- **Type Checking:** TypeScript support
- **Package Manager:** npm/pnpm

## Language Composition

- JavaScript: 94%
- CSS: 4.7%
- HTML: 1.3%

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or pnpm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/mTornam/golden-bowl.git
cd golden-bowl
```

2. Install dependencies:
```bash
npm install
# or
pnpm install
```

### Development

Start the development server:

```bash
npm run dev
```

The site will be available at `http://localhost:5173`

### Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

### Linting

Run ESLint to check code quality:

```bash
npm run lint
```
